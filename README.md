# Sosa-Ecommerce

This is a fullstack web application built using only JavaScript, HTML, and CSS. The application includes the following pages:

- **Index**: Homepage
- **Shop**: E-commerce shop page
- **Events**: Events page
- **Services**: Services page
- **Contact**: Contact page
- **Others**: Additional pages as needed

## Project Structure

```
Sosa-Ecommerce/
|-- frontend/
|   |-- index.html
|   |-- shop.html
|   |-- events.html
|   |-- services.html
|   |-- contact.html
|   |-- others.html
|   |-- styles/
|   |   |-- style.css
|   |-- scripts/
|       |-- script.js
|
|-- backend/
|   |-- server.js
```

## How to Run

1. Navigate to the `backend` folder.
2. Run the server using Node.js.
3. Open the frontend HTML files in a browser.
